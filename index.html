Месечен цикъл на събитията

  • 1-ва седмица (Събития, базирани на фрагменти) -> Въртележка / Магазин на Камила / Дуел на шампиони
  • 2-ра седмица (Събития, базирани на подобряване на танкове) -> Gacha GO / Светлината на Зората
  • 3-та седмица (Събития, базирани на оборудване) -> Плячката на бикоокото (Bullseye Booty)
  • 4-та седмица (Базирани на значки за изследвания / гориво / ускорения) -> Lucky Discounter

Начини за получаване на фрагменти за герои всяка седмица

  • Опасността дебне (рали срещу бумъри): x1 Оранжев фрагмент / x5 Лилави фрагмента -> ЕЖЕДНЕВНО
  • Пълна готовност (финална награда): x2 Оранжеви фрагмента / x7 Лилави фрагмента -> ЕЖЕДНЕВНО
  • Седмична награда за подаръци: x6 Оранжеви фрагмента -> СЕДМИЧНО
  • Сага зомбита (ниво 9): x24 Оранжеви фрагмента -> СЕДМИЧНО
  • Магазин за слава: x10 Оранжеви фрагмента -> СЕДМИЧНО
  • Оранжеви / Лилави камиони: x4 ~ x12 Оранжеви фрагмента -> ЕЖЕДНЕВНО
